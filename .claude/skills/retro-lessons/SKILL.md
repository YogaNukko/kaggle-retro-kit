# 段 6 — 教訓と還元先

1. `lessons.md` を埋める: 教訓 1 件 1 行、区分（領域知識 / モデル / CV / 運用）、根拠（カードか自陣の実験）、還元先。
   領域に固有の教訓は次の似たコンペ向けのメモへ、どのコンペでも効くもの（CV の作り・提出の選び方・時間の使い方）は
   自分のコンペ雛形やチェックリストへ、道具の不足は backlog へ
2. ユーザーが還元先のファイルを指定したら、貼れる段落を `competitions/<slug>/backport/<還元先>.md` に書く
   （頼まれない限り他のリポジトリには書き込まない）
3. 記事の下書き（任意）: `templates/article.md` → `article.md`。他人の解法の記述には記事の URL、動画はポスター PNG か Release の URL

教訓には根拠を付ける。カードも実験も無い一般論は書かない。
